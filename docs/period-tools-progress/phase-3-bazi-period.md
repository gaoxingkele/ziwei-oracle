## 核心实现要点

**70 行新算法（其余复用 lunar 库）**：

### 命理规则表（自定义）
- 三合：申子辰水、巳酉丑金、寅午戌火、亥卯未木
- 三会：寅卯辰东方木、巳午未南方火、申酉戌西方金、亥子丑北方水
- 三刑：寅巳申恃势、丑戌未无恩、子卯无礼
- 自刑：辰午酉亥
- 六害：子未/丑午/寅巳/卯辰/申亥/酉戌
- 五行生克：木→火→土→金→水→木（生）；木→土→水→火→金→木（克）

### 流月对命主关系算法
1. **十神**：`SHI_SHEN[日干 + 流月干]` 查 lunar 表
2. **藏干十神**：流月地支 → `ZHI_HIDE_GAN` → 每个藏干对日干十神
3. **刑冲合害**：流月地支 vs 原局 4 地支批量比对（冲/六合/半合/三会/三刑/自刑/六害）
4. **五行 delta**：流月干支带来的五行计数变化
5. **用神得失地**（B 级）：用神同类增量+1，相生增量+1，相克增量-1，按总分四档输出

### 用神简化判定
- 身强（日主同类+生我五行 ≥ 4）→ 用神=克我/我克/我生
- 身弱 → 用神=同类+生我

## 准确性等级

| 字段 | 等级 |
|------|------|
| 本命四柱（年/月/日/时柱） | A — lunar 库标准 |
| 流月干支 | A — 五虎遁标准 |
| 流月十神 | A — SHI_SHEN 查表 |
| 藏干十神 | A — ZHI_HIDE_GAN + SHI_SHEN |
| 刑冲合害 | A — 完整传统规则表 |
| 五行 delta | A — 计数加减 |
| **用神得失地** | **B 级（参考性）** — 简化判定，门派可能差异 |
| **用神判定（身强身弱二分）** | **B 级** — 仅参考；本期不做月令旺衰精细分析 |

scope_note 字段已写入返回值，提示 LLM 用神状态属参考性。
